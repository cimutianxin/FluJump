# 实验：深度方向翻转的机制解释（C9，升档关键③）

- **日期**：09-26-16
- **目的**：解释"中层 vs 末层编码的 jump 方向相反"（08-01-22 留下的开放问题：亚型身份全层贯穿、~0.94 平坦可分，为何 jump 方向随深度翻转）。预注册假设 H1–H6 见计划；判定规则与阈值均预注册。

## 方法

自包含新目录 `validation_exp/depth_reversal/`（只读复用资产，不改任何现有 workflow）：

- **G1 层几何**（`g1_layer_geometry.py`）：31 层 × 双标签重训 Ridge probe（P0 回归断言通过，同 reversal_sites/g2 基准 ±0.06）；每层算 cos(w, d_ST)、logit offset/within 分解、H2 方向竞争基 {亚型内宿主轴 a_H1/a_H3, 亚型组成轴 b=μ_H1−μ_H3} 的 w 投影份额、亚型间/内方差比；shuffled-label null ×20；关键层 5 seed。
- **G2 残差流**（`g2_residual_stream.py`）：h_L = h_0 + ΣΔ_l 逐 block 贡献分解（mean-pool 与差分可交换，全层 npy 直接算），对 L17/L28/L30 probe × 双标签给出亚型内 gap 的逐 block 累积剖面。
- **G3 残基×层贡献**（`g3_residue_layer_contrib.py`，GPU ~4 min）：全 31 层逐残基贡献 c_i=((h_i−m)/s)·w 在线聚合到 1039 个 MAFFT 列（einsum 自洽断言 2e-05；与旧 npy 对账中位 0.000——旧 npy EOS 包含不对称 max 0.15–1.07，记录用）。sep（train± 读出剖面）、dposH7、**d_within（亚型内 ± 逐列剖面，reversal_sites 未分解过）**；功能/诊断位点集读出指数 + 10k 置换 + Fisher/BH。
- **G4 注意力归因**（`g4_attention.py`，GPU ~1.5 min）：2709 行分层子集，eager attention（smoke 断言 30 层返回）；逐层残基 received-mass 归一分布聚合到列坐标系；同位点集判定 + 熵。
- **G5 规模核查**（`g5_scale_geometry.py`，CPU）：650M（34 层）/3B（37 层）全层重训 probe，重复 gap/cos/方差比 + cos(w_best, w_last)。
- **G6 交叉读出**（`g6_cross_readout.py`）：probe 层 a × 数据层 b（13/17/22/28/30）交叉矩阵——分解"表示旋转"与"读出旋转"的各自贡献。

## 结果

### 框架修正（G1）：翻转的载体是"亚型内 ± gap"，不是 offset

AUC 平移不变 ⇒ 亚型整体偏移 offset w·(μ_ST−μ_train) **数学上不可能影响 AUC**。
operative quantity = **亚型内 gap** w·(μ_ST+ − μ_ST−)：

- ρ(gap_H7, AUC_H7) = **0.896 / 0.837**（jump / jump_human，p ≤ 4e-9），符号一致率 81–94%；H5 侧 ρ = 0.894 / 0.935。
- gap 符号随深度翻转：jump mid(13–22) gap 均值 **+4.63**（AUC 0.646）→ late(28–30) **−11.77**（AUC 0.223）；jump_human mid +0.80 → late **−25.18**（AUC 0.162）。
- **H5↔H7 反相关的几何本质**：ρ(gap_H5, gap_H7) = **−0.702 / −0.773**（p ≤ 3.5e-07）——同一个 w 把 H5+ 排在 H5− 之上的方向，恰好把 H7+ 排在 H7− 之下，且反相关系随深度翻转。

### 方向旋转（G1）：w_17 ⊥ w_28

- cos(w_17, w_28) = **−0.005（jump）/ +0.015（jump_human）**——中层与末层的 train 解**近正交**（两者 train CV 均 ~0.99）。翻转不是"同一方向反向"，而是 train 解空间随深度旋转、两个近正交解对 holdout 亚型内排序给出相反答案。
- seed 稳定性：L13/17/28 的 w cos = 1.0000，L30 0.94。

### H2 方向竞争：NULL

- share_subtype（w 在 H1vH3 身份轴上的份额）随深度上升（ρ=+0.55/+0.59，q≈0.003），但**与 H7 AUC 无相关**（ρ=+0.23/+0.04，落入 shuffled null 区间 [−0.53,0.38]/[−0.45,0.29] 内，p=0.75/0.95）——预注册的 ρ≤−0.7 不成立。train 内 H1/H3 阳性率 4 倍差提供的身份轴捷径**不是**翻转驱动。
- 注意 share_subtype 绝对值仅 0.001–0.009：w 的 99% 住在 {宿主轴, 身份轴} 张成之外。

### H4 残差流定位（G2）

- L28 probe 的 H7 gap 负贡献主要来自 **13–22 段 block**（jump −11.91 / 总 −12.14；jump_human −20.04 / 总 −21.63），L>20 段仅 −1.20/−4.31——亚型内差异由中层段写入、末段仅携带。
- 注意 L30 probe 的逐 block 分解出现巨型对消项（mid +460.78 / 总 −11.70），解释受限，如实记录。

### H5 位点读出转移：NULL（G3）

- func_frac（功能位点集读出份额）mid−late 差 = −0.0021/+0.0003（置换 p=0.68/0.95）；diag_frac 差 −0.0098/−0.0115（p=0.12/0.076）——**预注册的"中层读功能位点、末层读诊断位点"不成立**；Fisher 富集无一过 BH q<0.05（功能列 19、诊断列 30、valid 列 586）。
- d_within 剖面给出**翻转驱动列**（late−mid 最负 top）：jump = HA1_12/271/46/71/274/202/43/144 + HA2_124；jump_human = HA1_202/71/274/43/46/27/203 + HA2_124/185——**6/10 双标签共享（HA1_43/46/71/202/274 + HA2_124）**，全部非经典 RBS（与 §2 / reversal_sites 一致，信号弥漫分布式）。
- 管线交叉验证：dposH7 late bottom-20 与 reversal_sites L28 驱动集重叠 7/20、core 集 9/20——复现 B6 结果；d_flip top-20 与驱动集仅 2/20（gap 翻转与整体推负是不同位点集）。

### H6 注意力佐证：NULL（G4）

- attn func_frac(H7+) mid−late = −0.0037/−0.0040（置换 p=0.19/0.18）；与 G3 读出指数跨层相关 ρ=−0.05/−0.20（p=0.81/0.30）；熵 mid 6.21 vs late 6.31（平坦）——注意力路由不随深度在位点集间重分配，与 08-01-22"亚型 probe 全层平坦"互洽。

### G6 交叉读出：表示旋转 × 读出旋转的复合

固定 w_17 读出：H7 gap 在 L22 数据 +11.90 → L28 数据 **−6.82**（表示效应 **−18.7**）；固定 L22 数据：w_17 读出 +11.90 → w_28 读出 **−14.63**（读出效应 **−26.5**）。jump_human 同构（−16.8 / −21.4）。**两个因素同量级共存**：H7 ± 差异在表示中随深度转向，且不同深度的 ridge 解读出该差异的方向也旋转。
（诚实备注：gap 是 AUC 的主导因素但非全部——w_17@L30 jump_human gap≈+0.4 而 AUC 0.669，分布形状效应存在。）

### G5 规模普适（650M/3B）

三规模同构（每层 probe 全协议重训）：

| 规模 | ρ(gap_H7, AUC_H7) | ρ(gap_H5, gap_H7) | best 层（gap 变号点） | cos(w_best, w_last) | 末层 gap / best 层 gap |
|---|---|---|---|---|---|
| 150M | 0.896 / 0.837 | −0.702 / −0.773 | L17/L13（变号 21–26） | −0.005 / +0.015 | −11.8~−25.2 / +4.6~+0.8 |
| 650M | 0.634 / 0.652 | −0.626 / −0.312 | L5/L3（变号 [5,6]/[3,4]） | −0.001 / +0.010 | −10.1/−15.7 vs +2.8/+1.7 |
| 3B | 0.680 / 0.791 | −0.591 / −0.699 | L2/L2（变号 [1,5]/[2,3]） | +0.018 / +0.014 | −4.4/−10.6 vs +3.5/+3.0 |

- **gap 变号点与 scale_replication 的 target-val 选层精确重合**（L5/L3/L2）——"最优深度"就是 within-gap 尚未变号的最深点。
- **"最优相对深度随规模前移"的机制**：gap 变号边界随规模前移（150M 21–26 → 650M 3–6 → 3B 1–5），可迁移窗口随之收窄到更浅的层。
- cos(w_best, w_last) 三规模全 ≈ 0（|cos| ≤ 0.018）——**解的近正交旋转是跨规模普适结构**。

## 结论

**机制解释（回答 08-01-22 开放问题）**：深度方向翻转发生在**亚型内 ± 排序**层面，而非亚型整体偏移层面（offset 平移不变）。其结构是：train 任务（H1+H3，~0.99 易分）的线性解空间很大，ridge 解的方向随表示深度近正交旋转（cos(w_17,w_28)≈0）；中层解恰好把 H7 亚型内 ± 排对（gap>0）、末层解排反（gap<0），且同一旋转对 H5 起反相作用（ρ=−0.70/−0.77）——H5↔H7 trade-off 与深度翻转是同一几何事实的两个侧面。交叉读出显示表示旋转与读出旋转同量级复合。位点/注意力层面均无重分配（H5/H6 null）——信号保持弥漫分布式，翻转不是"换了读哪些位点"，而是"同一批分布式特征的读出方向旋转"。

### V1：AA 身份线性解码（`v1_aa_identity_decode.py`，600 条 × ≤120 残基，闭式 ridge）

- acc 全层饱和 0.9999–1.0000（token 身份全程线性可读，ESM 已知性质）——T1 在 acc 上 null（饱和），身份信息从未丢失。
- 敏感几何指标成立：**margin U 形**（L0 0.1246 → **L20 最低 0.1147** → L28 0.1242），**participation ratio U 形**（L4 峰 104 → **L17 最低 16.5** → L29 53.4，2.5× 再扩张）；**ρ(margin, gap_H7) = −0.70 / −0.62**（p ≤ 1.9e-4），**ρ(PR, gap_H7) = −0.57**（p=8.9e-4，jump；jump_human −0.28 n.s.）；anisotropy 无趋势（p ≥ 0.07）。
- 解读：中层 = 表示最大压缩段（有效维度与身份置信双最低），恰为可迁移窗口；末层沿 token 身份相关方向再扩张。B1"末层被 MLM 目标再锚定"以**几何**形式成立——不是身份内容出现，而是身份相关方向的占比回升，稀释/旋出了承载可迁移信号的压缩方向。**最优层 ≈ 压缩最低点（label-free 判据）**。

### V2：亚型内 logit ↔ 阴性 consensus 典型性（`v2_h7_lineage_distance.py`，纯 CPU）

- sanity：g1_probes 复算 L17/L28 AUC_H7 与 g1 JSON 一致（<0.01）。
- 阴性子集（无 ± 成分混杂）Spearman ρ(logit, identity_to_阴性consensus)：H7 mid **+0.327/+0.186** → late **−0.150/−0.368**；H5 镜像 mid **−0.395/−0.306** → late **+0.478/+0.301**。
- H7 ± 在典型性上几乎无分离（identity 中位 0.891 vs 0.896，rank-biserial ≈ −0.03）——典型性轴是 train 标签**未约束**的自由度，其耦合符号随深度与谱系翻号，正是 w 旋转在亚型内序列层面的直接可测表现。
- 判定：T1 ✅（H7 耦合随深度翻号）；T2 以镜像形式成立（H5 非"无变化"对照而是反向翻号——两亚型互为对照）。

### 整合机制句（V1/V2 后更新）

深度翻转 = **读出旋转**（w 近正交，三规模 cos≈0）× **表示几何相变**（中层最大压缩 → 末层身份再锚定扩张）的叠加；亚型内典型性耦合的深度翻号（H5/H7 镜像）是其在序列层面的直接可测足迹。可迁移窗口 = 压缩段，其边界（gap 变号点）随规模前移。

## 踩坑

1. 旧 all_layers npy 的 EOS 包含不对称（非 batch 最长行 mean 含 EOS 位）——sanity 对账只能以中位数判行对齐（max 在 L30 达 1.07），与 reversal_sites G2 的 lens off-by-one 同类。

3. joblib 跨进程传大矩阵极慢——worker 内 mmap 自读。
4. matplotlib 默认字体无 CJK——图件一律英文标注（g1/g3 图已重生成）。
