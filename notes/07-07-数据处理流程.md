# FluJump 数据处理流程

> 2026-07-07 | `python datascripts/run_pipeline.py`

## Pipeline

```
raw (18,680) → clean (11,714) → CD-HIT 99% (2,362 毒株) → simplified.csv (20 列)
```

## 步骤

### Phase 1: 数据清洗 (`clean_data.py`)

| 过滤 | 排除量 |
|------|--------|
| PDB 条目 | 3,384 |
| seq_length <400 or >600 | 3,580 |
| synthetic construct | 2 |

无 collection_year 的 586 条**保留**（year=-1），不参与时间计算。
改进 host 推断：英文关键词 + 科学属名 + strain_name 模式，修正 697 条。

**最终**: 18,680 → 11,714 (62.7%)

### Phase 2: CD-HIT 聚类 (`cluster_strains.py`)

99% identity (阈值对比: 90/95/97/99/99.5%，99% 时 cross-species 信号最多)。

```
H1: 4,113 → 908  H3: 4,682 → 693  H5: 2,020 → 499  H7: 899 → 262
合计: 11,714 → 2,362 毒株
```

### Phase 3: 简化标签 (`build_jump_labels.py`)

直接输出 `data/processed/all_subtypes_simplified.csv` (20 列):

| # | 列 | 说明 |
|---|-----|------|
| 1 | cluster_id | 99% identity 聚类 ID |
| 2 | subtype | H1/H3/H5/H7 |
| 3 | cluster_size | 该毒株包含的 isolate 数量 |
| 4 | consensus_ha_seq | 代表 HA 序列 |
| 5 | serotype | 主要血清型 |
| 6-14 | first_{host}_ym | 各宿主最早检出 YYYY-MM (缺月→06) |
| 15 | host_categories | 涉及宿主列表 (&#124;分隔) |
| 16 | **label_is_jump** | 任意跨物种 (75, 3.5%) |
| 17 | jump_interval_cat | 动物→人正间隔: 0-6m/6-12m/12m+ |
| 18 | **label_is_jump_human** | 含人类跨物种 (48, 2.2%) |
| 19 | jump_interval_human_cat | 含负: negative/0-6m/6-12m/12m+ |
| 20 | label_jump_source | 来源宿主 (avian/swine/bovine) |

## 教训

- NCBI 通用查询不完整，需定向补充关键宿主
- Host 推断需多层匹配: 英文关键词 → 科学属名 → strain_name
- CD-HIT 99% identity 是最优粒度
- 跨物种定义应包括 animal↔animal (中间宿主)
- 负 jump_interval 不代表反向传播，是检测偏差
